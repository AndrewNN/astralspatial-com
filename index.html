01 — What we do
  1. 001

    Creative

    Sound designed for a specific room. The work spans spatialized sound design, interactive pieces, and existing compositions adapted into spatial formats. Each piece is built for where it will be heard.

    • Spatialized sound design
    • Interactive programming
    • Adaptation to spatial formats
    • Composition for arrays
  2. 002

    Systems

    The logic and the artist-facing workflow, often running on hardware someone else already installed. A room built by others, made usable, is the service.

    • Control logic
    • Room tuning
    • System architecture
    • Q-SYS programming
    • Ambisonic templating
    • Dante routing
    • Dolby Atmos
    • Wave field synthesis
  3. 003

    Fabrication

    Speakers, haptics, and electroacoustic instruments, built as objects for one room rather than specified from a catalogue. Each piece is sized and finished for the space it ships to.

    • Custom speakers
    • Custom haptics
    • Acoustic & electroacoustic instruments
    • Enclosures

Fig. 02 Reforesters Laboratory, Williamsburg 24.2 channel
  1. W/01

    Reforesters Laboratory

    Reforesters Laboratory is a 24.2 channel listening room and adaptogen cafe in Williamsburg. The scope was software, not hardware: Astral Spatial built the control logic and tuned the room already installed. The deliverable is a workflow. A visiting artist arrives with their own work and plays it in ambisonics without an engineer rebuilding the room for them.

    • Scope — software
    • Q-SYS programming
    • Ambisonic templating
    • Dante routing
    • Allen & Heath SQ-5
    • d&b audiotechnik
    • Status — complete
  2. W/02

    Private Commission

    A custom speaker installation is underway, the first project where the physical build is Astral Spatial's own. The client cannot be named yet.

    • Status — in progress
    • Client — unnamed
